# Container finding review — 27 October 2026

Reviewer: Codex automated engineering reachability assessment under the owner's routine maintenance mandate. This records a technical release exception, not a human approval or a statement that the listed packages are patched. Exceptions expire on 3 November 2026 and do not apply when the scanner reports an available fix.

## Gate and fixes

Every release must scan the final installed packages in all five published images on both amd64 and arm64. The scanner itself is pinned by digest. Scanner failures, architecture mismatches, expired exceptions and new high/critical findings block bundling. Raw reports and an assessment summary remain release artifacts. Package paths, OS release, installed version, finding ID, severity, image kind and architecture must match the explicit exception. No wildcard suppression or blanket unfixed exclusion is used.

The Python certificate store is updated to certifi 2026.10.18. Root GitHub App operations use the same reviewed public roots through an explicit checksum-checked SSL context; host or environment roots are not implicitly added. This addresses the measured stale emSign roots on Oracle without changing trust for other host applications. The public bundle, upstream license and wheel checksum are included in the checked release. The separate native research environments require a root-held installation receipt and independently measured inventories before source activation. Node is updated to the 24.22.1 security base; the [official October release](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases) fixes the Brotli decoder and other runtime issues. Current Debian package updates replace the affected Perl and PCRE2 builds. OpenClaw's core pin remains 2026.9.7, with separately locked, hashed replacements for vulnerable bundled Undici and brace-expansion, and targeted SDK, body-parser and Zod overrides. Vite moves to 8.3.3. The actual assembly inventories are retained in each image.

Pip 26.2.2 has its own private older libraries even when the application's urllib3 is current. The assembly replaces its msgpack with the hash-pinned 1.2.3 pure Python implementation and urllib3 with 2.8.0. It removes the deprecated pkg_resources backend, using Python 3.13's existing importlib metadata backend. The bundled venv bootstrap wheel is rebuilt with those actual files and a new RECORD. Pip's CycloneDX inventory is updated to the code actually supplied; the original inventory hash is retained in the assembly receipt. Normal pip, venv creation and offline wheel installation/import are executed in the image's functional check. These are maintained packaging backports, not an assertion that the upstream pip artifact is unchanged.

The complete hosted scan also identified affected packages in the stock web image. The web assembly now builds the same Caddy 2.11.7 standard modules with Go 1.26.10 and a committed module/checksum lock, updated x/net, x/crypto, certificate fallback roots and JOSE v4.1.6. Alpine's available Brotli/curl fixes are applied. The compiled package list and Go build information remain inside the image. The build fails if the unsafe legacy OpenPGP packages enter the compiled graph. Both architectures remain mandatory scan targets.

## Reassessment

Before expiry, check vendor fixes and refresh both architecture scans. New fixed versions block even an otherwise matching exception. Reassess immediately if adding a privileged file executor, host devices or cgroups, shared HTTP caching, terminal-description processing or Perl archive extraction. CI retains every residual finding; these records do not establish a vulnerability-free system or close production ownership acceptance.
