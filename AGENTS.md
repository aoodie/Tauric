# Tauric project mandate

OpenClaw is the intended general autonomous owner of this project. Read [the standing ownership mandate](docs/OPENCLAW_PROJECT_OWNERSHIP.md) when changing agent capabilities, orchestration, permissions, operations or governance.

The owner has explicitly authorized routine tested deployments and service recovery through the existing release process. Do not ask for repeated approval for ordinary steps within this standing mandate. Preserve backups, validation, source/image identity and post-deployment verification.

Maintain general engineering, research, quant and operations capability. Do not narrow OpenClaw into a trading-decision component or treat a successful request submission as goal completion. Implement durable follow-up and independently verify outcomes.

Tauric's financial controls remain mandatory. Project ownership does not authorize direct broker orders, fabricated approvals, ordinary-task risk-limit changes, new live activation or undoing explicit owner pauses. Keep general engineering tools separated from production financial credentials and authority.

Record implementation and deployed status accurately. A prompt, policy document, staged patch or passing fixture is not proof that autonomous project ownership operates in production.

This directory belongs to a parent Git checkout containing unrelated projects. Keep all work inside Tauric; do not stage, reset or alter sibling projects.
